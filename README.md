# Sean 每日新闻播客

Private (unlisted, itunes:block) daily Chinese news podcast feed, hosted on GitHub Pages.

- Feed: https://seanexk.github.io/sean-podcast/feed.xml
- Add in Apple Podcasts: Library → ⋯ → Follow a Show by URL.

New episode: put the mp3 in `episodes/`, add an entry to `episodes.json`, run
`python3 gen_feed.py https://seanexk.github.io/sean-podcast`, commit and push.
